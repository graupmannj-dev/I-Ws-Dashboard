# AIBA Atlas (public front-end)

The production landing page at \`/\` is generated by \`dashboard/build_atlas.py\` **after** the original strict daily GDELT/Wikipedia and decision-brief builds have passed. The existing watchboard remains at \`/classic.html\`, and source-audited case decision briefs at \`/ops/\`.

## Globe
- Pure browser Canvas 2D orthographic projection, with drag rotation, scroll/zoom buttons and a slate color scheme. No CDNs, API keys, geocoding service or external map runtime required.
- Country polygons: **Natural Earth 1:110 million Admin-0 countries, public domain**, from https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_admin_0_countries.geojson. The subset \`countries.geojson\` includes only the selected country geometry and display names. Source information: https://www.naturalearthdata.com/about/terms-of-use/.
- Geography: the ten current colored watchspot coordinates are **theater display anchors**, not precise incidents. Grey reporting points use screen-only separation around those anchors, representing dated sourced observations without supplied GPS coordinates. The screen jitter does NOT represent a geospatial uncertainty circle.
- US geographic combatant command overlays are **schematic reference regions**. They are not official Areas of Responsibility and must not be used as operational command boundaries. A vetted GeoJSON of current command boundaries would be required for accurate overlays.

## User interface
- Hotspot severity reflects manually sourced standing state: Active conflict, Escalation watch, Watch, etc. An empty Critical filter is accurate where no reviewed dossier has been classified Critical.
- The color and labels are current **standing** state. The time slider does not backdate those categories. It filters **reports with known source dates** (day precision) over 1/3/7/30 days or full history through the cursor.
- A pulsing icon means fresh **new case-specific decision evidence**, not a warning that an attack is imminent. If a feed ran but no new change was established, no pulses are shown.
- Data-poor but genuinely new GDELT actor-pair anomalies are not plotted at invented coordinates; their count is shown in the sidebar.
- Shipping and air-activity overlays use optional measured sources; connection, missingness, and observation age are visible. Syndicated news headlines never become measured tracks. See the overlay setup below.

## Deployment and testing

The existing \`Validate and publish AIBA\` GitHub Actions workflow builds the classic page, runs its strict data checks, and only then builds the globe page. Browser assets are shipped under \`/dashboard/\`. No change to the schedule, publication approval requirement or strict GDELT completeness gate.

Local quick test:
\`\`\`bash
python aiba_v5.py --output-dir _site
python ops_render.py --state /tmp/aiba-atlas-empty --site _site
python fusion_briefs.py --state /tmp/aiba-atlas-empty
python decision_render.py --state /tmp/aiba-atlas-empty --site _site
python dashboard/build_atlas.py --site _site
python scripts/check_atlas.py _site
node --check _site/dashboard/atlas.js
python -m http.server 8765 --directory _site
\`\`\`

Navigate to http://localhost:8765. Use a local HTTP server rather than opening HTML as a \`file://\` URL because the browser reads relative JSON assets with \`fetch\`.

The optional GitHub PR \`atlas-browser\` job runs headless Chromium to interact with the visible controls and check runtime errors. A fully successful preview still does not establish the accuracy of future escalation prediction. Historical event/non-event scoring and precise geolocation remain research and collection tasks, not completed capabilities.

## Measured overlays and official notices

The six new switches are independent of the historical reporting timeline:
ADS-B aircraft, AIS vessels, airspace restrictions, maritime restrictions,
US travel advisories, and US embassy departure/operations notices. All start off.
Selecting a layer opens a source-linked notice list; aircraft/vessels also have
clickable markers and trails accumulated while the page is open. State advisories
shade matched countries by official level (1–4); pink embassy notice shading takes
precedence when both switches are enabled. Unmatched countries remain uncolored.
Natural Earth display-name matching has a small alias table; not every advisory
has a matching map territory. Notices without coordinates remain in the list.

Sources implemented:

- OpenSky state vectors: https://openskynetwork.github.io/opensky-api/rest.html.
  OAuth client credentials required. Operational product use requires written
  permission under https://opensky-network.org/about/terms-of-use. No credentials
  or license are supplied by this change. Bounding-box queries default to the
  Gulf region; `AIBA_TRACK_BBOX=south,west,north,east` changes the collection area.
- AISStream: https://aisstream.io/documentation/. Requires `AISSTREAM_API_KEY`.
  Server-side WebSocket only, with bounded regional subscriptions and reconnect
  backoff. This Python adapter uses uncompressed messages and is subject to the
  provider's uncompressed bandwidth limits. It does not promise satellite or
  complete offshore coverage. Tracks are not recorded unless the live server runs.
- FAA public TFR list: https://tfr.faa.gov/tfrapi/exportTfrList?format=json and
  linked downloadable XML. Only explicit UTC schedules and merged WGS84 straight
  boundaries are supported. Unsupported local-time/recurring schedules and
  failures are counted and omitted; the feed reports **partial** coverage. This
  is US TFR coverage, not a worldwide airspace closure service. Dates in XML
  labeled with local timezone codes are intentionally not guessed.
- Danish Maritime Authority public navigational warnings:
  https://niord.dma.dk/rest/public/v1/messages?domain=niord-nw
  (schema: https://docs.niord.org/public-api/api.html). Includes published notices
  with explicit closed/prohibited/restricted/exclusion wording in their English
  title, with original points/polygons and dates. Open-ended restrictions stay
  eligible only while the source confirms publication and the snapshot is fresh.
  This is regional Danish coverage, not global sea lane coverage. NGA's public
  endpoint returned HTTP 503 during validation; it is not represented as connected.
- State Department: https://travel.state.gov/_res/rss/TAsTWs.xml. Country levels
  are parsed separately from departure/operations mentions. A mention in an
  advisory is labeled **review source**, never automatically promoted to a
  verified current partial/full evacuation or current staffing status. The
  full official advisory remains the authority. Generic evacuation advice does
  not create an embassy departure marker.

### Static Pages snapshots

`python dashboard/collect_layers.py --output _site/layers.json` collects public
sources and optionally OpenSky when configured. Run before `build_atlas.py`.
Without collection, the builder writes an explicit not-connected payload.
Collection failure clears the relevant layer rather than substituting zero
activity or retaining old measurements. Public feed collection is included in
production builds; PR/offline builds make no network requests.

The browser hides track observations older than ten minutes and notice snapshots
not checked within 48 hours. Active restrictions also honor their individual
validity dates. Every layer shows its collection time and status; snapshots are
not advertised as continuously live. The existing daily Pages cadence cannot
provide live aircraft or ships by itself.

### Live backend

Install `requirements-layers.txt` for AIS, then use a built site:

```bash
AIBA_LAYER_FEED_URL=api/layers python dashboard/build_atlas.py --site _site
python dashboard/collect_layers.py --serve _site --output _site/layers.json
```

Set `OPENSKY_CLIENT_ID`, `OPENSKY_CLIENT_SECRET`, and/or `AISSTREAM_API_KEY` as
server environment secrets; never place secrets in JavaScript, JSON or commits.
The server binds localhost:8765 by default. It polls OpenSky every 120 seconds
(configurable `--interval`, minimum 60), subject to account credits, and receives
AIS continuously. The browser refreshes every 30 seconds. Ship and aircraft
position timestamps, not collection time, determine measurement age.

For production, host this collector as a persistent Python service behind HTTPS,
use `--bind`/`--port` for the service platform, and point the Pages build's
`AIBA_LAYER_FEED_URL` at its public `/api/layers` endpoint. Set
`AIBA_ALLOWED_ORIGIN=https://graupmannj-dev.github.io` for that browser origin.
No backend is provisioned by this PR. An externally supplied endpoint must serve
this version-1 schema over HTTPS and permit the Pages origin through CORS.

Optional `--reviewed path.json` imports source-reviewed maritime or embassy
notices. Top-level `maritime` and `embassies` arrays contain `id`, `title`,
`source`, HTTPS `url`, timezone-qualified `valid_from`/`valid_until`, `detail`,
optional `country`, optional exact `lat`/`lon`, and optional GeoJSON `geometry`
(Polygon, MultiPolygon, or LineString). Import only original official geometry;
never guess a sea lane polygon from headline text. Imports must be re-reviewed
before their end date. This path supports additional regional official notices
without claiming an automated global closure feed.
